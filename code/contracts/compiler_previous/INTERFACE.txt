# R22 bounded source derivation interface, design v1

All arms receive the same request, initial_state, public_scope, native state_schema,
public facts, IR manual and output_schema.json, under one shared model-call budget.
This is exposed-task measurement replication. All eight task templates have been
seen: banking 1/4/5/11, Slack 10/13/14, travel 14. No unseen-task claim is made.

The identical strict output shape is `{derivation_version:"r22.1", contract,
nodes, bindings}`. `contract` is the ordinary strict r22.1 contract evaluated by
the separately repaired executor. The literal arm requires `nodes=[]` and
`bindings=[]`; the derived arm executes its declared DAG and substitutes operands.
No emitted Python or task ID/answer table is executed. Nodes contain only an ID,
one enumerated operation, references to earlier nodes, and strict typed parameters.

Runtime API: `compile_annotation(annotation, packet, public_task, *, mode="derived",
public_facts=None, required_targets=None)` returns `{status, contract,
provenance, diagnostics}`. Status is `ok`, `unknown` or `error`; an unavailable or
ambiguous derivation is construction UNKNOWN, not task FAIL. Malformed IR is a
construction ERROR. Only an `ok` contract is passed to the repaired task executor.
The secondary `mode="verified"` reuses exactly the derived model response and
compares its literal operand claims with computed operands before substitution.
A known claim mismatch returns construction UNKNOWN with a distinct mismatch
reason. It does not turn that mismatch into a task-level FAIL. Literal and derived
claims remain preserved in all receipts.

`packet` contains `task_request` (or request), `initial_state`, optionally
`state_schema`. `public_task` is the public common scope. No reference/compiler
expected values enter these arguments. `public_facts` supplies equally public
native facts if needed, e.g. `{"message_sender":"bot"}` from the registered
message tool's fixed actor. These are shared source inputs, not runtime answer
constants. Runtime source nodes read roots initial_state/request/scope/facts.
Canonical packet/scope and facts hashes bind every receipt; transfer binds a new
packet explicitly while preserving the emitted program exactly.

Bindings target scalar ordinary-contract operands: check/selector values,
query entity/value, and dynamic path/property strings. They cannot change
obligation IDs, operators, profile, newness or role. Derived coverage requires
all check/selector values and query entity/value, plus state paths/properties
that the public scope declares dynamic. The caller may supply the same explicit
value-free required_targets list to both representations. Static structure stays
under the common repaired scope admission policy. A correct computation from an
incorrect selected source field remains possible and is tested independently.
Execution/provenance is not semantic certification.

The DAG provides source/span reads, projection/filter/unique, lookup_many,
flatten/zip, zero-filled group_count over an explicit domain, argmin/argmax,
sort/enumerate, Decimal arithmetic and bounded text construction. Every operation
is generic. `lookup_many(missing="empty_array")` explicitly makes a fully observed
absent map key an empty bucket; it cannot convert an unavailable map to empty.
This supports listed empty channels. Numeric ties in argmin/argmax abstain.
Ranking uses an explicit total sort key (count descending, name ascending);
unknown/incomparable or duplicate total keys abstain. Booleans are not numbers.
No free prose, external network, regex, automatic selection, fallback answers,
reference labels or gold tables are used by runtime.

Structural budgets: 64 nodes, 128 bindings, DAG depth 16, 10,000 row visits,
10,000 intermediate items, 1 MiB aggregate source JSON, strings at most 16 KiB,
Decimal precision 40, magnitude at most 1e12, no nonfinite values. Request numeric
constants come from exact start/end spans and parse_decimal; arithmetic constants
0/1/100 and booleans are the only direct constants. Parameters such as source
pointers, filter fields, bounded indices and text replacement needles are
candidate choices, never resolved answers. Literal selectors may be brittle;
source permutations and independently computed transfer targets expose this.

Development uses original exposed packets. Methods/programs are frozen before
confirmation. The preregistered five new source worlds per template use fixed
program transfer with no API adaptation; worlds 1–3 additionally use fresh paired
construction with the same mutated packets and shared budget. Cardinality and
common obligation shapes stay fixed (Slack10 has three nonmembers; Slack14 four
rank slots). Root authors new source worlds/native states/references independently
of this runtime. Valid, invalid and unavailable observations remain distinct.
Source-sanity programs and controls live outside runtime and never become a
competitive arm or model prompt input.
